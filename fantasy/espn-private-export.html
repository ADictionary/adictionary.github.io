Private ESPN league export

Create a local JSON file containing your ESPN league's teams, rosters, standings, matchup schedule and one selected week's player box scores.

1. Install the exporter bookmark

The green button below copies a small bookmarklet. It does not export your league from this page. You install it once, then run it from your private ESPN league page.

Click the button to copy the bookmarklet URL.
If copying is blocked, show the bookmarklet URL

Select all the text below and copy it. Paste it into the URL/address field of a new browser bookmark.

2. Add it to Chrome bookmarks (one time only)

1
Show the bookmarks bar with ⌘ + Shift + B.
2
Right-click an empty area of the bookmarks bar and choose Add page….
3
Name it ESPN League Export. Paste the copied bookmarklet into the URL field, then save.
4
Keep this bookmark. You can reuse it whenever you want to refresh your league data.
Important: Do not click the bookmarklet while you are on this helper page. It must be run from your signed-in ESPN league page, because that is where the browser can use your existing ESPN session.

Live matchup graphs: install the score tracker

ESPN gives private leagues a live score snapshot, not a ready-made score timeline. This extra bookmark collects the scores about every 90 seconds while your ESPN league tab stays open, so Fourth & Goal can draw a real matchup graph for every team pairing.

Copy this into a separate Chrome bookmark named “ESPN Live Score Tracker”.
Show tracker bookmarklet text if copying is blocked

Select all the text and copy it into the URL field of a new bookmark.

1
Create a separate bookmark named ESPN Live Score Tracker and paste this new code into its URL field.
2
Open your private ESPN league page and click the tracker bookmark once. Confirm the season and scoring week. It will say that tracking has started.
3
Leave that ESPN tab open while the games are being played. The tracker collects matchup scores about every 90 seconds.
4
When you are finished, click the same bookmark again. It stops tracking and downloads a JSON file with the league data and the captured score timeline. Import that file into Fourth & Goal Fantasy.
Important: The tracker only runs while the ESPN tab remains open. If you close or reload that tab, its in-memory capture ends. It makes read-only ESPN requests and does not read or store password or cookie values.

3. Export your private league

1
Open ESPN Fantasy Football in the same Chrome profile and sign in normally.
2
Navigate to your private league's home or matchup page. The address should contain your league ID, usually as ?leagueId=123456.
3
Click the ESPN League Export bookmark you created.
4
Confirm the season and scoring week when prompted. Your browser should download a JSON file.
5
Return to Fourth & Goal → Fantasy and select that JSON file under Choose ESPN export JSON.
The exporter makes read-only requests to ESPN using your browser's existing signed-in session. It never reads, displays, copies or transmits your password or cookie values. The downloaded JSON stays on your computer until you select it for import.

4. If it still doesn't work

If clicking the bookmark does nothing: check that the bookmark's URL begins with javascript:. Some browsers remove this when creating bookmarks; use the manual copy field above and paste it again.

If you see “Open your ESPN league page first”: you clicked it from the helper page. Open your ESPN league and click the saved bookmark there.

If ESPN returns HTTP 401/403: sign in to ESPN again, reopen the league, and retry.

If you see a CORS or network error: the browser or ESPN may be blocking the request. The helper cannot override ESPN's access controls.

ESPN's Fantasy API is unofficial and can change. The export contains private team names, owners, rosters, matchup scores and player statistics. Treat the JSON file as private league data.
