About this project

Fourth & Goal

Fourth & Goal is an independent NFL scoreboard, free prediction game and fantasy player tracker. View game leaders, track a roster using standard full-PPR scoring, and make free game predictions.

The page reads the current-week NFL scoreboard from ESPN’s publicly accessible JSON feed. ESPN does not provide a stable public developer contract for this endpoint, so the feed format or availability could change. If the feed is unavailable, use the refresh button to try again later.

Data source: ESPN NFL scoreboard.
